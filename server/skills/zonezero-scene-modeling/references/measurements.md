# Measuring from known objects

| Reference | Size (ft) | Use it to |
|---|---|---|
| Story height | 9–10 floor to floor | wall height h = stories × 9.5 (to the eaves) |
| 2-car garage door | 16 W × 7 H | garage wing width ≈ door + 4–8 |
| 1-car garage door | 9 W × 7 H | |
| Front door | 3 W × 7 H | porch width ≈ 2–4 doors |
| Window | 3 W × 4 H (bedroom), 5–6 W picture | count windows per story to estimate wall length (≈ 1 per 10–12 ft) |
| Car | 6 W × 15 L × 5 H | driveway ≈ 18–20 wide for 2 cars |
| Fence | 6 H, posts every 8 | fence length = posts × 8 |
| Gutter | runs the full eave | one gutter per wall that has an eave |
| Mature juniper | 4–10 H | |
| Foundation shrub | 2–5 H | |
| Mature conifer (forest) | 60–120 H | forest height |
| Typical lot | 50–80 wide | neighbor spacing 10–25 ft between houses |

## Roof pitch and height
- Roof rise above the eaves ≈ 0.28 × the short span (hip, ~6/12) or 0.36 × span (gable, ~8/12, craftsman).
- A front gable whose peak reaches the main ridge is a wing with h close to the main h.
- A one-story garage wing has h ≈ 9–11.

## Footprint sanity
- Two-story suburban: main block 30–45 × 28–40.
- Ranch: 50–70 × 25–35, h ≈ 9–10.
- Garage wing (2-car): 20–24 × 20–24 (if it projects forward, d = how far it sticks out, often 8–14).
